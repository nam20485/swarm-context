GitHub forbids self-approval, and `nam20485` is the sole maintainer/admin. A no-bypass 1-approval rule would make every PR unmergeable. Agents and non-admin tokens must still open PRs and get reviews; the admin retains the ability to push/merge directly when needed.

- **Coverage gate scope: entire scripts dir (Option C)** (2026-07-24): `ci-cd.md` mandates >85% coverage. Three scope options were considered: A (two fully-tested files only, 93%), B (all 3 tested files, add ~5 tests to hit 87%), C (entire scripts dir, write ~60 tests to reach 85%). Chose C because it honestly reflects the full codebase and doesn't game the gate by excluding under-tested files. Result: 93.91% (802/854) across all 11 skill scripts via 89 new tests from 3 parallel worker subagents.
